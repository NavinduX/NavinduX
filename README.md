## 🚀 Featured Project

<div align="center">

### 🔗 BloxLogicAI
**An Intelligent Blockchain-Based Supply Chain Anomaly Detection Prototype**

<a href="https://github.com/NavinduX/BloxLogicAI"><img src="https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github&logoColor=white" alt="Repository"></a>

</div>

Supply chains lose trust when records can be edited after the fact and anomalies go unnoticed until it's too late. BloxLogicAI writes shipment events to an immutable ledger and runs a machine-learning model over them, so suspicious batches are surfaced in real time and every record can be independently verified.

| | |
|---|---|
| 🤖 **ML anomaly detection** | Flags irregular shipments and batch behaviour |
| ⛓️ **Blockchain-backed records** | Shipment events written to smart contracts |
| 🔐 **Tamper-resistant history** | Transactions verifiable, never silently edited |
| 👥 **Role-based access** | Separate views for each supply-chain actor |
| 📊 **Analytics dashboard** | Interactive monitoring of batches and alerts |
| 🔎 **Transparent verification** | Any record traceable back to its on-chain proof |

**Stack:** `Python` · `Flask` · `Streamlit` · `Scikit-learn` · `Solidity` · `Web3.py` · `Ganache` · `SQLite`

```
Shipment Data ──▶ Flask API ──▶ ML Anomaly Engine ──▶ Alerts
                     │                                   │
                     ▼                                   ▼
              Smart Contract (Solidity)          Streamlit Dashboard
                     │
                     ▼
              Immutable Ledger (Ganache / Ethereum)
```
