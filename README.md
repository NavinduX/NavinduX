Featured Project

BloxLogicAI

An Intelligent Blockchain-Based Supply Chain Anomaly Detection Prototype






BloxLogicAI combines machine learning and blockchain to improve transparency, traceability and anomaly detection across supply-chain operations. It is designed as a practical prototype for monitoring shipment batches and preserving verifiable transaction records.

Core capabilities

Machine-learning-based anomaly detection

Blockchain-backed shipment records

Tamper-resistant transaction history

Supply-chain batch monitoring

Role-based access control

Interactive analytics and shipment verification

Built with

Python · Flask · Streamlit · Scikit-learn · Solidity · Web3.py · Ganache · SQLite
